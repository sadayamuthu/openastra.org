# OpenAstra Events Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `openastra.org/events`, a hub and per-talk pages for the online "OpenAstra Talks" series. Luma handles registration and YouTube Live handles streaming. Every talk page has its own link preview.

**Architecture:** Talks live in a plain data file (`src/data/events.js`). Pure helpers in `src/lib/events.js` work out status (upcoming/live/past), ordering, time formatting, `.ics` files and YouTube embed URLs. Two React pages (`/events`, `/events/:slug`) render from those. A post-build Node script stamps per-page `<title>`/OG/Twitter tags into copies of `dist/index.html` for `/events` and each talk, and writes `dist/sitemap.xml`.

**Tech Stack:** React 19, react-router-dom 6, Tailwind 3, Vite 7, Vitest 4 + Testing Library (jsdom), Node ≥ 20 (plain ESM script, no new dependencies).

**Spec:** `docs/superpowers/specs/2026-11-18-events-design.md` · Wireframe: `docs/wire/events.html`

## Global Constraints

- No new npm dependencies. No backend, no accounts, no email collection on openastra.org.
- Times are stored as UTC ISO 8601 (`2026-12-12T17:00:00Z`) and shown in the visitor's own time zone, with the zone named.
- Live window: `start ≤ now < start + durationMin`. `durationMin` includes Q&A and is shown as one length ("60 min, incl. Q&A").
- YouTube embeds use `https://www.youtube-nocookie.com/embed/<id>`.
- Hub tabs, in order: **All · Live & upcoming · On demand · Call for papers (soon)**. The "soon" pill is not clickable. Use the `?tab=` query (`live`, `on-demand`), following the Frameworks page's `?category=` pattern.
- The conference is not mentioned anywhere on the site.
- Style: reuse `Eyebrow`, `Pill`, `Button`, `ComingSoon`, `DoiTag` from `src/components/ui.jsx` and the paper/ink/rust tokens. Follow the wireframe.
- "Events" sits in `NAV_LINKS` between Research and About.
- Page titles: hub `Events · OpenAstra`; talk `<title> · Events · OpenAstra` (in-app). Prerendered OG title for a talk: `<title> · OpenAstra Talks`.
- The production `events` array ships **empty** (the real first talk isn't chosen yet). Tests use a fixture.

## Review Focus

1. **Visitor outside UTC:** a 17:00 UTC talk must read "10:30 PM" with an IST label in Asia/Kolkata, including when the local date is a different day. *(Task 1 test `formatWhen shows the visitor's zone and date`.)*
2. **Exact boundaries:** at `start` the talk is live; at `start + durationMin` it is past; one ms before `start` it is upcoming. *(Task 1 test `eventStatus boundaries`.)*
3. **Live with no usable stream link** (missing or not a YouTube URL): show "Stream link coming soon", never an iframe with `src="null"`. *(Task 3 test `live talk without a stream shows a placeholder`.)*
4. **Titles with `"`, `&`, `<`, `,` or `;`** must not break the prerendered meta tags or the `.ics` file. *(Task 1 test `toIcs escapes text fields`; Task 5 test `escapes HTML in meta`.)*
5. **No talks at all** (the production state): the hub shows "Next talk announced soon" and the recordings empty state, and prerender still writes `/events`. *(Task 4 test `empty hub`; Task 5 test `writes the hub with no events`.)*

### Task 1: Event data, fixture and pure helpers

**Files:**
- Create: `src/data/events.js`, `src/lib/events.js`, `src/lib/events.test.js`, `src/test/eventsFixture.js`, `src/data/events.test.js`

**Interfaces:**
- Produces (all in `src/lib/events.js`, all pure, `now` is a `Date`):
  - `eventStatus(event, now): 'upcoming' | 'live' | 'past'`
  - `eventEnd(event): Date`
  - `upcomingEvents(list, now): Event[]`: upcoming **and** live, soonest first
  - `pastEvents(list, now): Event[]`: newest first
  - `featuredEvent(list, now): Event | null`: the live one if any, else the soonest upcoming
  - `findEvent(list, slug): Event | undefined`
  - `formatWhen(event, { timeZone } = {}): string`, e.g. `Sat 12 Dec 2026 · 10:30 PM IST` (uses `Intl.DateTimeFormat('en-GB'…)` for date + `en-US` hour12 time + `timeZoneName: 'short'`; `timeZone` omitted means the browser's zone)
  - `formatDuration(event): string`, e.g. `60 min, incl. Q&A`
  - `toIcs(event, siteUrl = 'https://openastra.org'): string`: a VCALENDAR with one VEVENT (UID `<slug>@openastra.org`, DTSTART/DTEND in `YYYYMMDDTHHMMSSZ`, SUMMARY, DESCRIPTION = summary, URL = `${siteUrl}/events/<slug>`, LOCATION = `Online`), lines joined with `\r\n`, text escaped per RFC 5545 (`\\`, `\;`, `\,`, `\n`)
  - `icsHref(event): string`: `data:text/calendar;charset=utf-8,` + `encodeURIComponent(toIcs(event))`
  - `youtubeEmbedUrl(url): string | null`: accepts `youtube.com/watch?v=ID`, `youtu.be/ID`, `youtube.com/live/ID`, `youtube.com/embed/ID`; returns `https://www.youtube-nocookie.com/embed/ID`; anything else or null returns `null`
  - `videoFor(event, now): { kind: 'countdown' | 'stream' | 'recording' | 'none', embed: string | null }`: upcoming → countdown; live → stream (embed of `streamUrl`); past → recording of `recordingUrl` if it embeds, else of `streamUrl` if it embeds, else `none`

### Task 5: Prerendered link previews and sitemap

**Interfaces:**

- Note: GitHub Pages serves `dist/events/<slug>/index.html` for `/events/<slug>` (via a redirect to the trailing-slash URL) with HTTP 200, replacing the `404.html` fallback for those paths.
- Produces (named exports, plus a CLI entry guarded by `import.meta.url === pathToFileURL(process.argv[1]).href`):
  - `escapeHtml(s): string`
  - `withMeta(html, { title, description, url, image }): string`: replaces `<title>`, `meta[name=description]`, `og:title`, `og:description`, `og:url`, `og:image`, `og:image:alt`, `twitter:image`; inserts or replaces `twitter:title`, `twitter:description` and `<link rel="canonical">` before `</head>`. All values are escaped.
  - `eventMeta(event, site = 'https://openastra.org'): { title, description, url, image }` where title = `<event.title> · OpenAstra Talks`; description = `<UTC date, e.g. "Sat 12 Dec 2026, 17:00 UTC"> · Online · Free. <event.summary>` (date via `Intl.DateTimeFormat('en-GB', { timeZone: 'UTC', … })`); url = `<site>/events/<slug>`; image = `<site>/events/<event.image>` if set, else `<site>/og-image.png`
  - `hubMeta(site)`: title `Events · OpenAstra`, description `Talks from the people who build OpenAstra's frameworks. Live online, with recordings afterwards.`, url `${site}/events`
  - `renderPages(html, events, site): Array<{ path: string, html: string }>`: `events/index.html` plus `events/<slug>/index.html` per event
  - `sitemap(site, { navPaths, frameworkSlugs, eventSlugs }): string`: `<urlset>` with `/`, nav paths, `/<framework>`, `/events/<slug>`
  - CLI: reads `dist/index.html`, writes `renderPages` output under `dist/`, writes `dist/sitemap.xml`, and logs one line per file.
- Optional per-event `image` field: a file name under `public/events/` (1200×630).
