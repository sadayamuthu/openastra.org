About this talk

When several AI agents work on parallel branches, git merges their changes cleanly even when they contradict each other. This talk shows how MergeLock finds those semantic conflicts before merge, with a live demo on a real repo. For engineers and security leads running coding agents.

You'll leave with

  • Why "no conflicts" doesn't mean "safe to merge"
  • How to add MergeLock to CI
  • Open questions we're researching next
